# Fonts shipped with the studio

Both faces are under the SIL Open Font License 1.1, which allows bundling them with the application and serving
them from a public server.

- **Alexandria** (`alexandria/Alexandria-Variable.ttf`) — headings. https://fonts.google.com/specimen/Alexandria
- **IBM Plex Sans Arabic** (`plex-arabic/*.ttf`) — body text, and the fallback for printed pages.
  https://fonts.google.com/specimen/IBM+Plex+Sans+Arabic

**SF Mada** (the profile's own face) is NOT part of this repository: its licence restricts redistribution. The team
uploads it from the studio's settings page; it is kept in private storage and used only to print and preview pages.
